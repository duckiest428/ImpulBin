# EA FC 26 Companion App Clone

A modern React-based web application clone inspired by popular EA FC (FIFA) Ultimate Team companion sites. Features a responsive Squad Builder, a rich Player Database, and various filtering and sorting views.

## Features

- **Squad Builder:** Interactive pitch to build your dream team with drag-and-drop slots.
- **Player Database:** Explore the latest and most popular EA FC 26 players.
- **Responsive Design:** Beautifully crafted UI optimized for both desktop and mobile devices.
- **Real-time Stats:** Player cards visually displaying stats, chemistry, and prices.

## Tech Stack

- **React 18** (Vite)
- **Tailwind CSS**
- **React Router**
- **TypeScript**

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Deployment

This repository is ready to be deployed to standard static hosting platforms such as Vercel, Netlify, or GitHub Pages. The build command `npm run build` outputs static files to the `dist` directory.
