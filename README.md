# FUTBIN for Impulsum

A modern React-based web application clone. Features a responsive Squad Builder, a rich Player Database, and various filtering and sorting views.

## Features

- **Squad Builder:** Interactive pitch to build your dream team with drag-and-drop slots.
- **Player Database:** Explore the latest and most popular EA FC 26 players.
- **Responsive Design:** Beautifully crafted UI optimized for both desktop and mobile devices.
- **Real-time Stats:** Player cards visually displaying stats, chemistry, and prices.

## Tech Stack

- **React 18** (Vite)
- **Tailwind CSS**
- **React Router**
- **TypeScript**
